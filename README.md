# 📰 News App

A modern Flutter-based news application that delivers real-time news updates using API integration, with a clean UI and smooth user experience.

---

## 📱 Overview

**News App** is a cross-platform mobile application built using Flutter that allows users to browse the latest news across multiple categories such as Technology, Business, Sports, and Entertainment.

The app fetches real-time data from news APIs and presents it in a structured and user-friendly interface.

---

## ✨ Features

* 📰 Latest news headlines
* 🌍 Category-based news (Tech, Sports, Business, etc.)
* 🔍 Search functionality
* 📡 Real-time API integration
* ⚡ Fast and responsive UI
* 📱 Cross-platform (Android & iOS)
* 🔄 Pull-to-refresh support
* 🧩 Modular and scalable code structure

```bash
cd news_app
```

### 2️⃣ Install dependencies

```bash
flutter pub get
```

### 3️⃣ Run the app

```bash
flutter run
```
